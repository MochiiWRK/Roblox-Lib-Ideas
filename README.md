# roblox-lib-ideas

A dumping ground for open-source Roblox library ideas.

The Roblox ecosystem has a specific failure mode: every serious game rebuilds
the same five systems from scratch, badly, in isolation, and none of it ever
leaves the place file. This repo is the opposite of that. Post the library you
wish existed. Someone might build it. It might be you, in six months, when you
have run out of excuses.

**No idea is too dumb to post.** A half-formed "someone should make X" issue is
worth more than a polished library nobody needed.

## How it works

1. **Dump it.** Open an issue with the [Library idea](../../issues/new?template=idea.yml)
   form. Two sentences is a legitimate submission. Label it and move on.
2. **Let it cook.** People comment, argue about the API, point out that
   `SomeGuy/thing` already does 60% of it. Fine. That is the point.
3. **Promote it.** Once an idea has a real shape, it graduates to a spec file in
   [`ideas/`](ideas/) — scope, API sketch, open questions. Run
   `node scripts/promote.mjs <issue-number>` or write the file by hand.
4. **Claim it.** Want to actually build one? Comment on the issue, open a
   [Claim](../../issues/new?template=claim.yml), and the idea gets
   `status:claimed` plus a link to your repo. Implementations live in **your**
   repo, not this one. This repo is the index.

## Status vocabulary

| Status | Meaning |
| --- | --- |
| `idea` | Posted. Unexamined. Possibly cursed. |
| `speced` | Has a file in `ideas/` with real scope and an API sketch. |
| `claimed` | Someone said they are building it. Ping them before you duplicate. |
| `released` | Exists, is installable, link is in the spec file. |
| `abandoned` | Claimed then dropped, or decided against. Kept for the archaeology. |

## Rules, such as they are

- **Scope goes in the issue, not in your head.** "Armor lib" means nothing.
  "Armor lib that handles R6/R15/Rthro/custom rigs and moving accessories" is a
  proposal.
- **Prior art is not a rejection.** If something exists but is unmaintained,
  closed-source, or wrong, say so and post the idea anyway.
- **MIT or Apache-2.0** for anything built out of here, so it can actually be
  used in a monetized experience without a lawyer.
- **No self-promo issues.** Made a library nobody asked for? Great, open a PR
  adding it to `ideas/` with `status: released`. That is the front door.

See [CONTRIBUTING.md](CONTRIBUTING.md) for the spec-file format.
